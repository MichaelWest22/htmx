Full page load — links pre-rendered by server

Full page path: when the page is not served from cache (e.g. admin preview, or BigPipe disabled) the server can render the trigger button and link list directly into <drupal-contextual> in the initial HTML. No POST to /contextual/render, no <hx-partial>, no batch trigger element. connectedCallback fires on each <drupal-contextual> as the browser parses the page and wires the open/close behaviour immediately — the same code path as the htmx-delivered version.

The hidden inputs are absent — they are only needed for the batch POST path. The element ID is still present so a subsequent partial can re-render the region if needed (e.g. after an in-place config save).
