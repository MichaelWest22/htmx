This is the home page of our htmx4 real demo. Notice how the header, navigation, sidebar, and footer remain completely stable while only this main content area updates.

🎯 What's happening here:

  • hx-boost:inherited on body converts all links to AJAX
  • hx-history-elt on main ensures only this area swaps during history navigation
  • Advanced boost config: target:"main" select:"main" swap:"innerHTML strip:true show:none"
  • Server returns real HTML files - no mocking needed!
  • Key: innerHTML strip:true removes outer element, show:none prevents scrolling
